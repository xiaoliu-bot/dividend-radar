# 高股息雷达

A 股高股息标的筛选与技术面择时看板。每交易日收盘后自动更新，静态页面托管在 GitHub Pages。

核心思路一句话：**基本面负责"选什么"，技术面只负责"什么时候买"**。

---

## 筛选逻辑

五层漏斗，从全市场约 5400 只标的逐层收敛：

| 层级 | 条件 | 目的 |
|---|---|---|
| 1 基础清洗 | 剔除 ST / 退市 / 北交所，总市值 ≥ 50 亿 | 规避壳股与流动性风险 |
| 2 股息率门槛 | 近一个年度股息率 ≥ 3% | 保证分红回报的绝对水平 |
| 3 分红持续性 | 连续分红 ≥ 3 年，分红率 15%–85% | 排除一次性分红与掏空式分红 |
| 4 盈利质量 | ROE ≥ 8%，净利同比 ≥ -35%，负债率 ≤ 75% | 避开"高股息陷阱" |
| 5 技术面打分 | 趋势 40% + 动能 35% + 量能 25% | 决定进场时机 |

### 为什么要设这些看起来奇怪的上限

**分红率上限 85%**：一家公司把利润几乎全分掉，要么是找不到值得投的项目，要么是大股东在抽血。20%–60% 才是"既愿意分、又留得住钱扩张"的健康带。

**股息率过高反而扣分**：股息率 = 每股分红 ÷ 股价。股价半年跌 40%，股息率会自动从 4% 飙到 6.7%，但这是市场在提前定价业绩暴雷。所以评分函数在 8% 以上是**减分**的，不是加分。

**连续分红年数比单年股息率权重更高**：单年一笔特别分红很容易做出漂亮数字，但明年就没了。

## 评分体系

```
综合评分 = 基本面 × 50% + 技术面 × 50%
```

**基本面（0–100）**
- 股息回报 35%：3%–6% 区间给满分，8% 以上倒扣
- 分红持续性 25%：连续 5 年及以上给满分
- 盈利质量 25%：ROE 20% 封顶
- 财务安全 15%：负债率 60% + 分红率 40%

**技术面（0–100）**
- 趋势 40%：均线多头排列、价格相对 MA20/MA60 位置、MA20 斜率
- 动能 35%：MACD 金叉与柱体变化、RSI 位置、KDJ
- 量能 25%：量比、量能趋势、ATR 波动率

评级映射：A+ ≥ 80 / A ≥ 72 / B+ ≥ 64 / B ≥ 56 / C+ ≥ 48 / C < 48

## 买卖信号

信号只在**已通过基本面筛选的池子里**触发，不会因为某只垃圾股金叉就推给你。每条信号带 1–3 星强度。

**买入类**：MACD 低位金叉（3★）、均线金三角（3★）、KDJ 超卖金叉、RSI 超卖回升、站上 20 日线、布林下轨支撑

**卖出类**：MACD 高位死叉（3★）、放量跌破 20 日线（3★）、RSI 超买、KDJ 高位死叉、中期趋势破位、触及布林上轨

操作建议按 `买入信号加权 - 卖出信号加权` 的净值判定，分为：重点关注买入 / 可分批建仓 / 持有观察 / 谨慎观望 / 减仓回避。

**止损用 2 倍 ATR，不用固定百分比。** 波动大的股票给更宽的空间，波动小的收紧，避免被正常震荡洗出去。

## 本地运行

```bash
pip install -r requirements.txt

# 完整跑一遍（约 10–20 分钟，取决于入选数量）
python scripts/build_data.py

# 调试模式：只分析前 30 只，几分钟出结果
python scripts/build_data.py --limit 30 --top 20

# 起本地服务看效果
cd web && python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

参数说明：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--limit` | 0（不限） | 进入技术分析的股票数上限，调试用 |
| `--top` | 40 | 最终输出到看板的数量 |
| `--workers` | 5 | 并发线程数，别开太高，akshare 背后是爬虫 |

环境变量 `DR_NO_CACHE=1` 可强制跳过本地缓存。

## 部署到 GitHub Pages

1. 新建仓库，把整个目录推上去
2. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**
3. 完成。Actions 会在每个交易日北京时间 16:30 和 21:00 各跑一次，自动更新数据并重新部署

想立刻看效果，去 Actions 页面手动触发一次 `每日更新高股息雷达`。

## 想改参数

筛选门槛都集中在 `scripts/build_data.py` 顶部的 `CRITERIA` 字典里：

```python
CRITERIA = {
    "min_dividend_yield": 3.0,    # 想更严格就调到 4.0
    "min_dividend_years": 3,      # 想只看老牌分红股就调到 5
    "min_roe": 8.0,
    "max_debt_ratio": 75.0,
    "min_payout": 15.0,
    "max_payout": 85.0,
    "min_mktcap": 5e9,
    "min_profit_yoy": -35.0,
}
```

评分权重在 `scripts/scoring.py`：`score_fundamental()` 里的四个子项权重、`score_technical()` 里的 40/35/25 分配，都可以按自己的偏好调。

## 风险提示

本项目所有输出由程序基于公开数据自动生成，**仅用于研究与学习，不构成任何投资建议或买卖推荐**。

需要清醒认识的几点：

- 技术指标本质是对历史价格的统计描述，对未来走势没有必然预测力，且天然滞后
- 分红数据来自年报，最新一期分红方案落地前，股息率是按上一年度数据估算的
- 高股息策略在牛市中通常跑输，在震荡市和熊市中相对抗跌，它不是全天候策略
- 评分高 ≠ 会涨。评分只是把一堆指标压缩成一个可排序的数字，方便缩小研究范围

股市有风险，决策请独立判断。

数据来源：akshare（东方财富公开数据）
